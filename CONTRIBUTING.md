# Contributing to Grid UI

1. Fork [gridplatform/grid-ui](https://github.com/gridplatform/grid-ui)
2. Create a branch from `main`
3. Open a pull request — do not push directly to `main`

```bash
cp -n .env.example .env
npm install
npm run dev
```

Point `VITE_GRID_API_URL` at a running [grid-core](https://github.com/gridplatform/grid-core) instance.
