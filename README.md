## 🎯 Purpose

Grid UI is the modern, responsive frontend interface for the Grid Infrastructure Orchestration Platform. Built with React, TypeScript, and Tailwind CSS for optimal developer experience and user interface.

## ✨ Key Features

- **Modern React UI** - Built with React 18 and TypeScript
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Real-time Updates** - Live deployment status and logs
- **Infrastructure Management** - Deploy, monitor, and manage resources
- **Environment Cloning** - One-click environment duplication
- **Cost Tracking** - Real-time cost monitoring and optimization
- **Dark/Light Mode** - User preference support

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/gridplatform/grid-ui.git
cd grid-ui

# Install dependencies
npm install

# Start development server
npm run dev
```
